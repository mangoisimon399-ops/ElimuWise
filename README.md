ElimuWise

Understand Your Funding. Plan Your Education.

About the Project

ElimuWise is a student education-finance planning platform designed to help students understand potential HELB funding bands, explore funding allocation guidance, and determine estimated course fees.

Main Features

- HELB band checking
- Student funding allocation guidance
- Course fee determination
- Student information submission
- Admin and agent features

Technologies Used

- Python
- Flask
- HTML and CSS
- IntaSend for payment integration

Installation

1. Install Python.
2. Install the required packages:
   "pip install -r requirements.txt"
3. Configure the required environment variables.
4. Run the Flask application using its configured entry point.

Important Notice

ElimuWise provides educational funding and fee-planning guidance. Funding bands, allocations, and fee figures are not official guarantees; students should confirm final decisions with the relevant institutions and funding authorities.

Security

Never publish passwords, API secret keys, or private student and financial records in this repository.
